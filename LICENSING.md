# ZWarden Licensing

ZWarden is licensed under the [Business Source License 1.1](./LICENSE) (BSL 1.1).

## What this means in plain English

**You can:**

- Self-host ZWarden to manage your own Project Zomboid servers
- Run it for your community, clan, or group of friends
- Read, study, and learn from the source code
- Fork and modify the code for your own deployment
- Contribute improvements back to the project

**You cannot:**

- Offer ZWarden (or a modified version) as a hosted service to third parties
  without a commercial license — for example, running a "PZ Server Management
  Platform" where other people sign up and pay you to manage their servers
  using this software

**On September 12, 2030** (or four years after any given version's first
release, whichever comes first), that version of the code converts
automatically to the **Apache License 2.0** with no restrictions.

## Why BSL?

ZWarden is a significant engineering effort built by a small team. The BSL
lets us keep the source code public — so you can verify the security claims,
learn from it, and self-host with confidence — while protecting the ability
to build a sustainable business around a hosted offering.

We believe the people who run PZ servers should be able to see exactly what's
managing their infrastructure. We also believe the people who build that
software should be able to make a living doing it.
