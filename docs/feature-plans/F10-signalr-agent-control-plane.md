## Objective

Open the **persistent Web ↔ Agent connection** that everything after Track C rides on. ZWarden.Web hosts a **SignalR hub over WSS** that an Agent connects to **outbound** (criterion 14: no inbound management port on a host). At the handshake the hub **authenticates the Agent by its F9 per-Agent credential** (via `IAgentCredentialVerifier`); on the first message it **negotiates the protocol version** against `AgentHello` (ADR 0020); it then tracks the live connection in an **in-memory registry** (the seam F11 will dispatch commands through), stamps a **persisted last-seen / connection state** for operator visibility, ingests **heartbeats** and the post-connect **state snapshot**, and **monitors** connection lifecycle. The Agent opens a **resilient outbound connection** using its stored `AgentTrustMaterial`, sends `AgentHello` → `AgentStateSnapshot` → periodic `AgentHeartbeat`, and **reconnects automatically**. F10 realizes the transport half of [ADR 0007](../adr/0007-agent-authentication-enrollment-credential-in-v1-0.md) (credential presented over WSS) and calls [ADR 0020](../adr/0020-agent-protocol-versioning-and-catalogue.md)'s pure negotiation rule at connect time.

## The settled decisions

1. **Handshake authentication is a SignalR `AccessTokenProvider` verified by a custom `"Agent"` authentication scheme (maintainer decision).** The Agent supplies its per-Agent credential through the SignalR client's `AccessTokenProvider`, re-invoked on every (re)connect. ZWarden.Web adds a custom `AuthenticationHandler` (scheme `"Agent"`) that reads the presented credential from the handshake (the `access_token` query on the WebSocket upgrade / `Authorization: Bearer` on the negotiate), calls F9's `IAgentCredentialVerifier`, and on success mints a `ClaimsPrincipal` carrying the resolved `AgentId`; the hub is `[Authorize(AuthenticationSchemes = "Agent")]`. This **rejects an untrusted Agent at the handshake, before any hub message runs**, puts the `AgentId` on `HubCallerContext.User` for the lifecycle handlers, and reuses the framework auth pipeline rather than an ad-hoc `OnConnectedAsync` check. Chosen over a hub filter / `OnConnectedAsync` verification because that runs after the connection is established and leaves the principal unpopulated.

2. **Connection state is an in-memory registry plus a persisted last-seen (maintainer decision).** An in-memory `IAgentConnectionRegistry` (`ConnectionId` ↔ `AgentId`) is **authoritative for "connected now"** and is the seam **F11 dispatches through**; it is populated in `OnConnectedAsync` and cleared in `OnDisconnectedAsync`. In parallel, connect / heartbeat / snapshot stamp a **persisted `LastSeenAt` + `ConnectionState`** on the `Agent` entity, so the operator UI has a last-seen even with no live connection and a background monitor has a staleness signal. **Single Web instance in v1.0 — no Redis backplane** (multi-instance scale-out is v1.1). This deliberately brings forward the *minimal* persisted connection-observation that F9's non-scope note parked at "F14/F16"; the richer observed-state/inventory surface still belongs to F14/F16.

3. **`AgentStateSnapshot` ships full plumbing with a minimal host payload (maintainer decision).** The Agent sends a real `AgentStateSnapshot` after (re)connect and ZWarden.Web ingests it (logs it, stamps last-seen, reconciles), but the payload is **`AgentStateSnapshot.Empty`** for now — the Agent manages no Servers until F13/F14 give it a Docker runtime and inventory. This exercises the snapshot round-trip end to end at F10 rather than stubbing it, without guessing at server-observation shape ahead of its feature.

4. **Delivered as one PR, TDD slices (maintainer decision).** A single PR on `feat/f10-signalr-agent-control-plane` closing #32 carries both the Web side (hub, auth scheme, registry, monitor, persistence) and the Agent side (SignalR client, reconnect, Hello/heartbeat/snapshot), each a red→green TDD slice/commit. The connection is one coherent story and reviews best as one; if it breaches the ~100K guardrail during build it splits at the Web/Agent seam (S1–S4 / S5), mirroring F9's fallback.

Decisions taken without escalation (low-risk, pattern-matching existing work), recorded here as the durable handoff:

- **Negotiation happens on the first `AgentHello`, not at the handshake (ADR 0020).** Authentication is at the handshake (decision 1); **version negotiation is the first hub exchange**: the Agent invokes a hub method passing its `Envelope<AgentHello>`, and the hub returns a `ProtocolNegotiationResult` (the existing F7 type) computed by `ProtocolCompatibility.Negotiate(envelope.ProtocolVersion, ProtocolVersionRange.Supported)`. On incompatible, the hub returns the result (carrying `RejectionReason`) and then `Context.Abort()`s; the Agent logs the reason and stops retrying a version the server will never accept. **No new protocol-message leaf is added** — the acceptance/rejection is a hub method return value, so the closed command/event vocabulary and its guard are untouched (trust-boundaries §9 rule 3).
- **Reconnect is the SignalR client's `WithAutomaticReconnect` with a bounded backoff.** On `Reconnected` the Agent **re-sends `AgentHello` (re-negotiating) then `AgentStateSnapshot`**; the credential is re-presented automatically because `AccessTokenProvider` is re-invoked. A fully-closed connection is retried from scratch on the same policy. A revoked/disabled Agent's re-handshake fails (decision 1), which is how revocation reaches a reconnecting Agent.
- **Transport liveness is SignalR's keepalive; application cadence is the domain `AgentHeartbeat`.** SignalR's built-in ping/keepalive detects a dead socket and drives `OnDisconnectedAsync`; the domain `AgentHeartbeat` (sent at `AgentOptions.HeartbeatInterval`, already declared) carries coarse self-health and stamps `LastSeenAt`. **Marking an Agent disconnected is driven primarily by `OnDisconnectedAsync`** (registry removal + persisted state + audit); the background monitor marking last-seen **stale** is a secondary safety net and **never promotes stale state back to current** (trust-boundaries §3).
- **Revoke / disable drops a live connection (best-effort, single-instance).** So that F9 revoke/disable *takes effect immediately* on an already-connected Agent rather than only at its next reconnect, the F9 `IAgentTrustService` calls `IAgentConnectionRegistry.TryAbort(agentId)` after a successful revoke/disable. This is the **only touch into F9's service**; the interface lives in `ZWarden.Application` (which Infrastructure already depends on) and the in-memory implementation lives in Web. Across multiple Web instances this needs the v1.1 backplane; single-instance v1.0 aborts directly.
- **No new ADR.** [ADR 0007](../adr/0007-agent-authentication-enrollment-credential-in-v1-0.md) records the one hard-to-reverse, surprising security decision (bearer credential over WSS, mTLS deferred, residual risk stated) and [ADR 0020](../adr/0020-agent-protocol-versioning-and-catalogue.md) records the negotiation rule; F10's remaining choices (auth-scheme handler, in-memory registry + persisted last-seen, snapshot plumbing, reconnect policy) are conventional realizations of them and live in this mini-plan. The **architecture-guard relaxation** (the Agent may now reference the SignalR client) is recorded here and enforced by an updated test (below).
- **No new typed-ID prefix and no new permission.** `AgentId` (`agt-`), `MessageId` (`msg-`) exist; the prefix registry stays at **20**. Connection lifecycle reuses the existing audit and (for any operator read of connection state) an existing permission — no new one is minted.

## Scope

1. **Domain — connection observation on the `Agent` aggregate.** Add `LastSeenAt` (`DateTimeOffset?`), `ConnectionState` (new `AgentConnectionState` enum: `Disconnected`/`Connected`), and `LastProtocolVersion` (`int?`) to `Agent`, with invariant-guarded mutators `MarkConnected(protocolVersion, now)`, `MarkHeartbeat(now)`, `MarkDisconnected(now)`. Trust state (F9) is unchanged; this is observed connection state only. No crypto, no I/O.
2. **Application — the connection seams.** `IAgentConnectionRegistry` (`TryRegister(agentId, connectionId)`, `TryRemove(connectionId)`, `IsConnected(agentId)`, `TryGetConnection(agentId)`, `TryAbort(agentId)` — the F11 dispatch seam and the F9 revoke hook). An `IAgentConnectionStateWriter` (or a method on the existing agent repository seam) to stamp connect/heartbeat/disconnect. The negotiation rule is already F7's pure function — no new application logic for it.
3. **Contracts — the hub protocol surface (no new message leaf).** A small `AgentHubProtocol` static (the hub path `"/agent/hub"` and the hub method names) so Web and Agent stay in lock-step, plus a `ProtocolJson`-based configuration helper for SignalR's JSON protocol. **No `[ProtocolMessage]`, not `AgentCommand`/`AgentEvent`** — like F9's enrollment DTOs, this is transport plumbing, not a message in the closed vocabulary, so the closed-vocabulary and discriminator guards are unaffected. The Hello handshake returns the existing `ProtocolNegotiationResult`.
4. **Web — the hub, the auth scheme, the registry, the monitor.**
   - `AgentAuthenticationHandler` (scheme `"Agent"`): reads the credential from the handshake, calls `IAgentCredentialVerifier`, builds a principal with an `AgentId` claim on success, `AuthenticateResult.Fail` (→ 401) + `Agent.ConnectionRejected` audit on failure. Registered via `AddAuthentication().AddScheme<…>("Agent", …)`.
   - `AgentHub : Hub` at `/agent/hub`, `[Authorize(AuthenticationSchemes = "Agent")]`. `Hello(Envelope<AgentHello>) → ProtocolNegotiationResult` (negotiate; abort on incompatible), `Heartbeat(Envelope<AgentHeartbeat>)` and `StateSnapshot(Envelope<AgentStateSnapshot>)` (ingest + stamp last-seen). `OnConnectedAsync`/`OnDisconnectedAsync` register/deregister + stamp persisted state + audit.
   - In-memory `AgentConnectionRegistry` (thread-safe `ConcurrentDictionary`); a stale replacing an old connection for the same Agent is handled (last-writer, old aborted).
   - `AgentConnectionMonitor` (hosted service): marks Agents whose `LastSeenAt` is older than a multiple of the heartbeat interval as stale for the operator view; never flips stale → current. It is also the safety net for a **Web crash**: if an instance dies without running `OnDisconnectedAsync` it leaves `ConnectionState = Connected` with nobody to clear it, so the monitor is what reconciles a persisted-`Connected`-but-silent record to stale.
   - DI/wiring: `AddSignalR` with the `ProtocolJson` JSON-protocol config, `MapHub<AgentHub>("/agent/hub")`, the auth scheme, the registry (singleton) and monitor. **No Web package add** — SignalR server is in the ASP.NET Core shared framework.
5. **Infrastructure — persistence + the F9 revoke hook.** Update `AgentConfiguration` for the three new columns; a per-provider **`AgentConnectionState` migration** (Sqlite + Postgres); the connection-state stamp implementation. `AgentTrustService.RevokeCredential`/`Disable` call `IAgentConnectionRegistry.TryAbort(agentId)` after the mutation (the only F9-service touch) + `Agent.CredentialRevokedWhileConnected` audit when a live connection was dropped.
6. **Agent — the outbound connection.** Add `Microsoft.AspNetCore.SignalR.Client`. `IAgentControlPlaneConnection` / `SignalRControlPlaneConnection`: a `HubConnection` to `ControlPlaneUri` + `AgentHubProtocol.Path`, `.WithAutomaticReconnect(bounded backoff)`, `AccessTokenProvider` revealing the stored credential from `IAgentTrustStore`, the `ProtocolJson` JSON-protocol config. `AgentConnectionInitializer` (`IHostedService`): after identity + enrollment, if trusted, connect → `Hello` (negotiate; stop on incompatible) → `StateSnapshot(Empty-host payload)` → start the heartbeat loop at `HeartbeatInterval`; re-send Hello+snapshot on `Reconnected`; log `Closed`; if un-enrolled, log and continue (the host still runs, per F8). Wired into `HostingExtensions` after enrollment.
7. **Tests** — domain mutators, registry, auth handler, negotiation, connection-state persistence (both providers), lifecycle audit, monitor staleness, the hub integration (in-memory host + real SignalR client), the Agent connection client + reconnect, the revoke-drops-live-connection path, the full enroll→connect→verified→heartbeat→revoke end-to-end, and the updated architecture guards.

## Non-scope

- **Command dispatch and the durable operations engine (F11).** F10 opens the connection and delivers the registry seam; F11 sends `AgentCommand`s down it and ingests `OperationProgress`/`OperationCompleted`. F10 wires Hello/Heartbeat/Snapshot only.
- **Real state-snapshot content (F13/F14).** The snapshot payload is `Empty` (host-level) until the Docker runtime and Server inventory exist. F10 proves the channel, not the contents.
- **Server registration and inventory, rich observed state, the operator connection UI (F14/F16).** F10 persists a *minimal* last-seen + connection state; the inventory surface and the dashboard are later.
- **mTLS and the certificate authority (v1.1, ADR 0007).** WSS gives transport + server auth; agent auth is the bearer credential. No `crt-`, no CA.
- **Hosted / multi-tenant connectivity and multi-instance scale-out (F10A, v1.1).** No Redis backplane, no per-tenant hub routing; single Web instance, default tenant, direct in-memory registry. This is a documented v1.0 assumption, not an oversight: [ADR 0005](../adr/0005-both-database-providers-ship-in-v1-0.md) states ZWarden.Web is a single process today and any future scale-out is a PostgreSQL-only deployment. Under N instances with no backplane, SignalR cannot route cross-instance and the per-process registry only sees its own sockets — F11 dispatch from the wrong instance misroutes and `TryAbort` on revoke can't reach a socket on another instance (revoke degrades to *safe*: it still takes effect at the Agent's next reconnect, since the re-handshake re-verifies). The persisted `LastSeenAt`/`ConnectionState` stays correct cross-instance because it lives in the shared DB. F10A adds a backplane and a distributed presence implementation of `IAgentConnectionRegistry` **behind the same interface** — the hub, F11 dispatch and the F9 revoke hook are unchanged.
- **Live credential *rotation push* to a connected Agent.** Revoke/disable *drops* the connection (it re-handshakes and fails); handing a rotated credential to a live Agent over the wire is a v1.1 nicety — in v1.0 the Agent re-enrolls/reconnects out of band.

## Security considerations

- **Agent authentication at the handshake, over WSS (ADR 0007).** Transport confidentiality and *server* authentication come from WSS; *Agent* authentication is the bearer credential verified by `IAgentCredentialVerifier` before any hub message runs. An unauthenticated or untrusted connect is refused at the handshake (401), audited, and never reaches a hub method.
- **The residual risk is ADR 0007's, restated:** a credential read off a compromised host lets an attacker connect *as* that Agent until it is revoked/rotated/disabled. F10 does not close this (mTLS in v1.1 does); it **honours the time-boxing tools** — revoke/disable fails the next handshake *and* drops any live connection immediately (decision above). This connection is the first Feature 40 attack-list surface.
- **No oracle at the handshake.** Auth failure is a generic 401 with the specific reason (bad credential vs. protocol-incompatible) **audited server-side only**, never returned to the Agent — matching F9's exchange.
- **The closed vocabulary is preserved.** The Hello handshake returns a value; **no free-form command string** and **no new command leaf** enter the Agent-facing contract (trust-boundaries §9 rule 3). The guard stays green.
- **Stale ≠ current (trust-boundaries §3).** On heartbeat loss the last snapshot is retained and marked stale; the monitor never promotes it back to current, and a reconnect re-sends a fresh snapshot before state is trusted again.
- **Default-tenant reliance (documented, as F9).** The handshake and connection-state persistence run under the default-tenant fallback with **no `IgnoreQueryFilters`**; F10A/v1.1 replaces the context for hosted, tenant-bound connectivity.
- **Agent stays file + BCL + transport only (trust-boundaries §9 rule 1).** Adding the SignalR client does not add Infrastructure/EF/Docker; the credential is revealed from the `SecretString` only to hand to `AccessTokenProvider` and is never logged. The arch guard is split to prove exactly this.

## Diagnostics

- **Connection lifecycle is fully audited** — `Agent.Connected`, `Agent.Disconnected`, `Agent.ConnectionRejected` (with a non-secret reason), `Agent.CredentialRevokedWhileConnected` — so an operator reconstructs an Agent's whole connection history in the F6 viewer with no credential in any record.
- **A rejected handshake names *why* server-side** (bad credential vs. protocol-incompatible) while the Agent sees only a generic 401 — the operator sees the reason, an attacker does not.
- **A protocol rejection is actionable** — it uses `ProtocolNegotiationResult.RejectionReason` ("Agent protocol N is below the minimum…"), so the log tells the operator which side must update.
- **The Agent logs its connection state transitions** (connecting / connected / reconnecting / closed / negotiation-rejected) structured, never logging the credential.

## Acceptance criteria

1. A trusted Agent (enrolled per F9) **connects outbound to `/agent/hub` over WSS**, is **authenticated at the handshake** by its per-Agent credential, and appears in `IAgentConnectionRegistry.IsConnected`; an untrusted/unauthenticated connect is **rejected at the handshake** and audited, reaching no hub method.
2. On connect the Agent's **protocol version is negotiated** against `ProtocolVersionRange.Supported`; an incompatible Agent is told the actionable reason and the connection is aborted; a compatible one proceeds.
3. The Agent sends `AgentHello` → `AgentStateSnapshot` (host-level, empty server set) → periodic `AgentHeartbeat`; ZWarden.Web ingests them and stamps a **persisted `LastSeenAt` + `ConnectionState`**; heartbeat loss marks the record **stale** without promoting it to current.
4. The connection is **resilient** — the Agent reconnects automatically with a bounded backoff and re-sends Hello + snapshot on reconnect; an un-enrolled Agent starts but does not connect.
5. **Revoke/disable takes effect immediately** — a live connection is dropped and a reconnect is refused at the handshake; every lifecycle transition is audited with **no credential in any record**.
6. The **agent references the SignalR client but no Infrastructure/EF/Docker**; **no `IgnoreQueryFilters`**; **no free-form command** and **no new protocol-message leaf** enter the Agent-facing contract; both provider migrations exist and the model matches; the offline tier is green with no warnings (Postgres verified on the networked tier before merge); the closed-set guards (prefix registry at 20, permission catalogue, built-in roles) are unchanged and green.

## Definition of Done
