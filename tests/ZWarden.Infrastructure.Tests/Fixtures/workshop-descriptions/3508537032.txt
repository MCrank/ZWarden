[h2]Build Support: B42.0.2 to B42.20.x SP/MP — Build 42 only[/h2]
[b]NeatUI Framework[/b] is a lightweight shared UI framework for [b]Project Zomboid Build 42[/b].

You normally do [b]not[/b] use this mod by itself. Install and enable it when another mod lists [b]NeatUI Framework[/b] as a requirement.

[b]Important:[/b] NeatUI Framework must load [b]before[/b] any mod that depends on it.

[hr]
[h2]What This Mod Does[/h2]
NeatUI provides reusable interface components and compatibility helpers shared by multiple mods.
[list]
[*]UI widgets, layouts and rendering helpers
[*]Shared styling and text utilities
[*]Scrolling/list/panel helpers
[*]Compatibility helpers for Build 42 UI/API changes
[*]Less duplicated UI code between related mods
[/list]

[b]NeatUI does not add gameplay features, recipes, items or world objects by itself.[/b]

Its visible effects come from the mods that use it.

[h2]Installation & Load Order[/h2]
[h3]Single Player[/h3]
Enable [b]NeatUI Framework[/b] and load it before dependent mods.

Example:
[code]NeatUI Framework
Neat Crafting
Neat Crafting addons[/code]

If NeatUI does not appear in the Mods list, make sure you are running [b]Build 42[/b].

[h3]Multiplayer / Host / Dedicated Server[/h3]
NeatUI must be included in [b]both[/b] server lists:

[list]
[*][b]Mod ID:[/b] NeatUI_Framework
[*][b]Workshop ID:[/b] 3508537032
[/list]

Check:
[b]Zomboid\Server<YourServer>.ini[/b]

Example:
[code]Mods=NeatUI_Framework;DependentMod1;DependentMod2;...
WorkshopItems=3508537032;WorkshopID1;WorkshopID2;...[/code]

[b]Important:[/b] adding `NeatUI_Framework` only to `Mods=` is not enough. Workshop ID [b]3508537032[/b] must also be present in `WorkshopItems=`.

NeatUI should appear [b]before dependent mods[/b] in `Mods=`.

Server and clients should use the same current Workshop files.

[h2]Linux Dedicated Servers / Lua Checksum[/h2]
Recent versions include path and line-ending cleanup intended to improve compatibility with case-sensitive Linux servers using:

[code]DoLuaChecksum=true[/code]

If you previously used `DoLuaChecksum=false` as a workaround, update NeatUI and dependent mods before testing again with checksum validation enabled.

For checksum testing or errors, please use:
[url=https://steamcommunity.com/workshop/filedetails/discussion/3508537032/844005195821120294/][b]Linux Server Checksum Feedback[/b][/url]

Useful reports include:
[list]
[*]Server OS / distro and PZ version
[*]Enabled NeatUI-dependent mods
[*]Exact checksum / missing-file error
[*]Relevant `Mods=` and `WorkshopItems=` lines
[/list]

[h2]Troubleshooting[/h2]
If NeatUI or a dependent mod does not work:
[list]
[*]Close Project Zomboid completely
[*]Make sure NeatUI is enabled and loads first
[*]In MP, check both `Mods=` and `WorkshopItems=`
[*]Make sure server and clients have updated Workshop files
[*]Verify Project Zomboid files in Steam if needed
[*]Test with only NeatUI + the affected dependent mod
[/list]

If the minimum setup works, add other mods back in small groups.

[h3]Clean Workshop Redownload[/h3]
If files appear outdated or mismatched:
[list]
[*]Close Project Zomboid
[*]Unsubscribe from NeatUI Framework
[*]Wait for Steam to remove it
[*]If necessary, remove the remaining folder:
[b]...\Steam\steamapps\workshop\content\108600\3508537032[/b]
[*]Subscribe again and let Steam finish downloading before launching the game.
[/list]

For dedicated servers, also make sure Workshop ID [b]3508537032[/b] was actually downloaded by the server/SteamCMD.

[h2]Removing NeatUI Framework[/h2]
NeatUI itself does not add world objects or gameplay content.

However, [b]do not disable or remove it while mods that require it are still enabled.[/b]

Check each dependent mod's own uninstall instructions separately. Some may register recipes, entities, XUI/WorldDictionary data or placed world content.

[h2]For Mod Authors[/h2]
Other mods are welcome to use NeatUI Framework.

Please use NeatUI as a Workshop dependency rather than repacking its files into your own mod. This avoids outdated duplicate copies and helps keep server/client versions consistent.
