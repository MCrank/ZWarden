[h2]Compatible with Project Zomboid B42.12.3–B42.20.x (SP/MP)[/h2]
[b]Modern Status[/b] is a flexible, highly customizable status HUD for [b]Project Zomboid Build 42[/b].

It turns your character’s condition into circular indicators, bars, and compact matrix layouts, with tooltips, presets, alarms, auto-hide, quick actions, performance modes, and support for several modded status systems.

[b]Safe to enable or disable in new or existing saves.[/b] Modern Status is a UI/HUD mod. It reads your character status and displays indicators. It does not add items, traits, recipes, world data, or permanent save changes.

[h2]Quick Access[/h2]
Right-click the [b]Health / heart button[/b] on the left sidebar to open:

[b]Modern Status > Global Settings / Presets / Multi Drag / Performance / Hide Vanilla Moodles[/b]

The old blue cog button can still be enabled from Mod Options, but it is disabled by default.

Basic setup:
[list]
[*]Open [b]Modern Status > Presets[/b] and load a bundled preset.
[*]Open [b]Global Settings[/b] or [b]All Indicators[/b].
[*]Hide or lock indicators you do not want.
[*]Move indicators manually, with Multi Drag, or through the matrix.
[*]Save your layout as a custom preset.
[/list]

[hr]
[h2]Panels and Matrix Layouts[/h2]
[list]
[*][b]Global Settings[/b]: presets, visibility, lock, grid, multi-drag, performance, tooltip options, and vanilla moodle hiding.
[*][b]All Indicators[/b]: manage every indicator from one place.
[*][b]Matrix Indicators[/b]: configure indicators linked to the shared matrix.
[*][b]Independent Indicators[/b]: configure indicators outside the matrix.
[*][b]Individual panels[/b]: fine-tune one indicator at a time.
[*][b]Presets panel[/b]: filter, load, overwrite, delete, and save presets.
[/list]

Matrix mode lets several indicators share one compact layout. [b]Fill Hidden Gaps[/b] lets visible matrix indicators reflow when another indicator is hidden or auto-hidden, keeping order without leaving empty spaces.

[hr]
[h2]Tooltips and Performance[/h2]
[img]https://i.imgur.com/dJm1Wax.png[/img]

Tooltips can show indicator name, value, thresholds, associated moodle, moodle title/description, and detailed contextual information.

Performance modes:
[list]
[*][b]Responsive[/b]: faster updates.
[*][b]Balanced[/b]: default balance between responsiveness and performance.
[*][b]Lightweight[/b]: slower updates for lower-end systems or heavy modlists.
[*][b]Custom[/b]: used when individual update intervals are edited manually.
[/list]

For extra UI performance, enabling [b]UI Offscreen Rendering[/b] and lowering [b]UI Rendering FPS[/b] in Project Zomboid options may also help.

[h2]Troubleshooting[/h2]
If Modern Status does not appear, settings/presets do not save, moodles behave strangely, or the UI looks broken after an update, try this with Project Zomboid closed:
[list]
[*]Unsubscribe from [b]Modern Status[/b].
[*]Wait until Steam fully removes the old Workshop download.
[*]Subscribe again.
[*]Verify game files:
[b]Steam Library > right-click Project Zomboid > Properties > Installed Files > Verify integrity of game files[/b]
[/list]

Then test in a new save with only NeatUI Framework + Modern Status

If it works, add your other mods back in small groups to find the interaction.

If it still fails, close the game and reset Modern Status files in:
[b]C:\Users\YOUR_USER\Zomboid\Lua[/b]

Current files:
[b]ModernStatusConfig.txt
ModernStatusPresets.txt[/b]

Older fallback files:
[b]ModernStatusConfig.lua
ModernStatusPresets.lua[/b]

Only delete the presets file if saved presets are broken or you want to remove custom presets.
